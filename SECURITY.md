# Security Policy

## Supported versions

LCoder is pre-1.0. Security fixes are applied to the latest code on `main`.

## Reporting a vulnerability

Use GitHub's **Security** tab and select **Report a vulnerability** to send a private report to the
maintainer. Include reproduction steps, affected versions or commits, and the impact when possible.

Do not include secrets, private source code, or other sensitive data beyond what is necessary to
demonstrate the issue. Please do not publish the report in a GitHub issue before a fix is available.
